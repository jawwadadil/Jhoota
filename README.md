# Jhoota Online Server

Online Bluff and team Trump for Jhoota Android version 0.95.

Rules revision 106 adds token-based seat recovery, best-of-three/five series
and a room-session scoreboard. The same room engine also powers the
Android app's nearby Wi-Fi/hotspot rooms and offline bots.

The Android app is maintained separately. This repository contains only the
server and its tests, without personal images, signing keys, or API secrets.

See [deployment instructions](server/DEPLOYMENT.md) for Render setup.
